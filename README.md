# UWE-Number-Detector

For my university module for Machine Vision, I created a Resistor and resistor bands detector on Google Colab, which uses 2 separate and originally created and labelled datasets and models produced for each of them. Specifically the models are a Resistor detection model and Resistor Bands detector model, and then coded a python program in Google Colab to also re order the bands order depending on resistor picture orientation and calculates the resistance of the detected resistors and output the result.
